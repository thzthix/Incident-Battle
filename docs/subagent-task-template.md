# Subagent Task Template

## 역할
- 예: 프론트엔드 구현자 A / 결과 화면 UX 개선안 / 인트로 케이던스 실험안

## 이번 작업 단위
- intro cadence / turn interaction panel / result feedback panel 중 하나만 선택
- 전체 앱을 건드리지 않는다.

## 목표
- 이번 단위에서 무엇을 더 좋아지게 만들지 1문장으로 적는다.

## 고정 계약
- data schema는 바꾸지 않는다.
- reducer phase 모델은 바꾸지 않는다.
- 다른 시나리오 파일은 건드리지 않는다.
- 공식 자산 복제는 금지한다.
