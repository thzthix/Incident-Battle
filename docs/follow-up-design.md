# 꼬리질문 설계

## 결론

설계했다. 지금 기준 MVP에서 가장 좋은 값은 아래다.

- 기본 시나리오: 꼬리질문 2개
- 대표 시나리오: 꼬리질문 3개까지 가능
- 한 턴당 최대 1개

이 규칙으로 가면 면접다운 압박은 살고, 전투 템포는 망가지지 않는다.

## 왜 2개 또는 3개인가

꼬리질문이 0개면 면접 느낌이 약하다.

꼬리질문이 턴마다 2개 이상이면:

- 플레이 시간이 과하게 길어지고
- 포켓몬 배틀처럼 한 번 행동을 내는 리듬이 죽고
- 유저가 `답변을 한 게 아니라 계속 혼난 느낌`을 받는다

그래서 균형점은:

- 보통은 2개
- 중요한 대표 시나리오만 3개

## 턴별 배치 규칙

### 1턴

역할:

- 우선순위를 확인한다.
- 첫 행동의 이유를 캐묻는다.

추천 질문 유형:

- `우선순위 검증형`
- `근거 요구형`

### 2턴

역할:

- 완화 전략의 리스크를 본다.
- 외부 의존성, 확산, 정합성 같은 제약을 붙인다.

추천 질문 유형:

- `제약 추가형`
- `리스크 점검형`
- `분기 전환형`

### 3턴

역할:

- 소통과 재발 방지를 본다.
- 정말 면접답변처럼 마무리하는지 확인한다.

추천 질문 유형:

- `커뮤니케이션 확장형`
- `재발 방지 확인형`

## 꼬리질문 taxonomy

### 1. 우선순위 검증형

예:

`왜 그 행동을 가장 먼저 두셨나요?`

### 2. 근거 요구형

예:

`방금 판단의 근거가 되는 지표는 무엇입니까?`

### 3. 분기 전환형

예:

`그 가설이 틀렸다면 다음으로 무엇을 보시겠습니까?`

### 4. 제약 추가형

예:

`우회 경로가 없다면 어떻게 하시겠습니까?`

### 5. 리스크 점검형

예:

`그 조치가 더 큰 문제를 만들 수 있는 경우는 없습니까?`

### 6. 커뮤니케이션 확장형

예:

`사용자와 팀에는 무엇을 어떻게 공유하시겠습니까?`

## 생성 규칙

LLM을 붙일 때도 완전 자유생성보다 아래 입력값을 주는 게 좋다.

- 현재 턴 번호
- 현재 전장 상태
- 플레이어가 선택한 행동
- 플레이어가 쓴 짧은 설명
- 이번 턴의 목표

그리고 출력은:

- 꼬리질문 1개
- 질문 유형 1개
- 질문 의도 1문장

이렇게 제한하는 게 가장 안전하다.

## 금지 규칙

- 한 턴에 꼬리질문 2개 이상 금지
- 같은 의미의 질문 반복 금지
- 상태와 무관한 질문 금지
- 지나치게 공격적인 어조 금지

면접관은 압박을 주되, unfair하면 안 된다.

## 샘플 운영 룰

- 튜토리얼: 1턴 후 1개만
- 일반전: 1턴 후 1개, 2턴 후 1개
- 대표전: 1턴 후 1개, 2턴 후 1개, 3턴 중 또는 종료 직전 1개
